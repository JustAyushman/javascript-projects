# Simple Calculator

A modern and elegant web-based calculator that performs basic arithmetic operations with an aesthetically pleasing glassmorphism user interface.

## Features
- **Addition, Subtraction, Multiplication, Division**: Performs basic mathematical calculations.
- **Glassmorphism Design**: Incorporates blurred backgrounds and semi-transparent layers for a premium look.
- **Input Validation**: Gracefully handles missing inputs and division by zero.
- **Responsive Layout**: Adjusts seamlessly for various device screen sizes and maintains a centered alignment. 

## Structure
- `index.htm` - The HTML backbone containing structure and layout.
- `style.css` - Custom styling reflecting an advanced, vibrant glassmorphism design.
- `script.js` - Lightweight JavaScript handling core operations and input validation.

## How to Run
Simply open the `index.htm` file in any modern web browser to interact. 
- Link : https://justayushman.github.io/javascript-projects/Caculator(Simple)/
